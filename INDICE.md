## 🚀 Cómo Empezar

### **Opción 1: Abrir Directamente (Recomendado)**
1. Abre la carpeta en VS Code
2. Click derecho en `index.html`
3. Selecciona "Abrir con Live Server"
4. ¡Listo! Se abrirá en tu navegador

### **Opción 2: Sin Live Server**
1. Abre `index.html` directamente en tu navegador
2. O arrastra el archivo a tu navegador

### **Opción 3: En Terminal**
```bash
# Si tienes Live Server instalado
npx live-server

# O con Python 3
python -m http.server 8000
```

## 🐛 Solución de Problemas

### Las imágenes no cargan
- ✓ Verifica que la carpeta `imagen/` esté presente
- ✓ Verifica los nombres de los archivos
- ✓ Usa `imagen/nombre-archivo.jpg`

### Los estilos no se aplican
- ✓ Limpia caché: Ctrl+Shift+Delete
- ✓ Recarga la página: Ctrl+F5
- ✓ Verifica que `styles.css` esté en la misma carpeta

### El carrito no funciona
- ✓ Abre la consola: F12
- ✓ Verifica que no haya errores
- ✓ Recarga la página
